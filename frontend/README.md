# Frontend

React + Vite + TanStack Router + shadcn/ui. See the [root README](../README.md)
for setup, the project structure and the guides.

- Pages live in `src/routes/` (one file per page; `routeTree.gen.ts` is generated).
- Add shadcn/ui components with `npx shadcn@latest add <name>` (https://ui.shadcn.com/docs/components).
- Icons: https://lucide.dev/icons
